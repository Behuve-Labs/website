# Behuve

Created by Noah Wong and Arnav Tripathy in 2026. Behuve is our running record of research we're doing and tools we're building from it.

The thesis: the best software comes from understanding a problem space deeply before building in it. So that's the order — read seriously, understand what's there, then build what's missing.

The blog is where we work through research in public. The tools are what we build when the thinking is done.

## Stack

- **Frontend**: Plain HTML/CSS/JS (no build step)
- **Backend**: Cloudflare Pages Functions (Workers)
- **Database**: Cloudflare D1 (SQLite)
- **Auth**: GitHub + Google OAuth with JWT session cookies
